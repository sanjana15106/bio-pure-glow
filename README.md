# BioPure

BioPure is a cloud-connected environmental monitoring and algae-based carbon capture analytics platform.

## Features
- Realtime telemetry
- CO₂ monitoring
- AQI analytics
- Temperature monitoring
- Cloud backend integration
- Realtime dashboard
- Future IoT scalability

## Technologies Used
- React
- TypeScript
- Supabase
- Lovable AI
- GitHub

## Future Scope
- ESP32 integration
- Real environmental sensors
- AI prediction models
- Industrial deployment
